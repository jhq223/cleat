# cleat-il2cpp

IL2CPP runtime bindings and metadata support for [cleat](https://github.com/jhq223/cleat).

This crate is maintained in the cleat workspace. Mod APIs and examples are documented in the [cleat API guide](https://github.com/jhq223/cleat/blob/main/docs/en/API.md).
